Why manual

Hooks in the syscall path.

Kprobe VFS interception falls over on this 4.4 tree under real I/O. The patch writes KernelSU into the same paths Android init actually uses — including newfstat so Zygisk can see the enlarged init.rc, and an SELinux exception so init can exec ksud on Android 15.

  • fs/exec.c do_execveat_common
  • fs/read_write.c vfs_read
  • fs/open.c faccessat
  • fs/stat.c stat + newfstat/fstat64
  • kernel/sys.c setresuid
  • kernel/reboot.c reboot
  • selinux/hooks.c init → ksu

Install

Use fastbootd.

Classic bootloader fastboot drops the transfer on this device.

Get the image

Download kernelsu-next-boot.img from GitHub Releases. It is not stored in git.

Flash 
adb reboot fastboot
fastboot flash boot kernelsu-next-boot.img
fastboot reboot
Manager

Install KernelSU Next Manager v3.3.0 (33214), grant ADB shell root, then check su.

Reproduce

Build it yourself.

./prepare-source.sh
./build-kernel.sh
cp /path/to/official/boot.img stock-boot.img
./repack-boot.sh

Do not flash on stock LG firmware

Unsupported V30 variants and the wrong LineageOS nightly can fail to boot. Keep the official boot.img from the same build, or the KernelSU v0.9.5 rollback image.
